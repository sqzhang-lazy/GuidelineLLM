# README assets

All images are stored locally and referenced with repository-relative paths. Keep `assets/` alongside the root `README.md` when copying or uploading this project.

## Badges

The static SVG badges in `badges/` were downloaded from [Shields.io](https://shields.io/). Local copies allow the README images to load without contacting an external image host. Their links lead to the AAAI proceedings, arXiv record, paper PDF, and code repository.
